# لعبة الطيور العربية

لعبة بسيطة للأطفال للتعرّف على أسماء الطيور باللغة العربية من خلال الصوت والصور.

## تشغيل اللعبة

افتح `index.html` في المتصفح، أو ارفع محتويات هذا المجلد إلى موقع ثابت. لإرشادات النشر خطوة بخطوة على GitHub Pages، راجع [الدليل](../../docs/GITHUB_PAGES_GUIDE.md).

## الملفات

اترك `index.html` وملفات اللعبة ومجلد `assets` معًا. يحتاج هذا المجلد إلى رفعين على GitHub: ارفع مجلد `assets` أولًا، ثم ارفع الملفات الموجودة مباشرة داخل مجلد اللعبة.
